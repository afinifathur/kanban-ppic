## 2. CANONICAL DATA SOURCES

No new tables or migrations were introduced. Data is pulled strictly from canonical ledgers verified during the Phase 3.5 Step 1 Audit:

1. **Pre-Tree Injection Defects (Cetak):**
   - Source: `lost_wax_print_executions`
   - Conditions: `status = 'FINALIZED'` and `qty_defect > 0`
   - Date mapping: `execution_date` (or `DATE(recorded_at)`)
   - Identity: `LostWaxPrintOrderLine.productionPlan.code` (or `LostWaxPrintOrderLine.code`)
   - Barcode: `-` (loose wax patterns prior to physical tree mounting)
2. **Post-Assembly Tree Defects (Rangkai, Lapisan 1–7, Oven):**
   - Source: `lost_wax_tree_defects`
   - Conditions: `defect_qty > 0`
   - Date mapping: `DATE(COALESCE(occurred_at, created_at))`
   - Identity: `LostWaxTree.printOrderLine.productionPlan.code` (or `LostWaxTree.getSourceCode()`)
   - Physical Barcode: `LostWaxTree.barcode`

## 3. FILTER SEMANTICS & MODES

### A. Filters Supported:
- `date_from`: Start date (`YYYY-MM-DD`, default: today)
- `date_to`: End date (`YYYY-MM-DD`, default: today)
- `stage`: `all` (Semua), `cetak`, `assembly`, `layer_1`..`layer_7`, `oven`
- `search`: Case-insensitive search across Production Code, Item Name, Barcode, and Defect Reason
- `production_code`: Dedicated drill-down parameter for isolating a specific production batch

### B. Display Modes:
- **Mode RINGKAS (Default):**
  - Aggregates defects grouped by `ProductionPlan.code` + `stage`.
  - Columns: `No | Kode Produksi | Nama Item | Tahapan (Stage) | Jumlah Rusak (pcs) | Total Kejadian | [ Detail ]`
  - Action: `[ Detail ]` button immediately switches to Mode Detail filtered by that Production Code.
- **Mode DETAIL:**
  - Granular transaction-level rows showing every defect entry down to the physical tree.
  - Columns: `No | Kode Produksi | Barcode Tree | Nama Item | Tahapan | Jumlah Rusak | Alasan Kerusakan | Operator | Waktu Kejadian`

## 4. KPI SUMMARY CARDS

Above the data table, real-time KPI metrics calculate totals dynamically adhering to the active filters:
- **Total Cetak:** $\sum \text{executions.qty\_defect}$
- **Total Rangkai:** $\sum \text{tree\_defects}[\text{stage}=\text{'assembly'}]$
- **Total Lapisan 1 s/d 7:** Individual counters per layer
- **Total Oven:** $\sum \text{tree\_defects}[\text{stage}=\text{'oven'}]$
- **GRAND TOTAL DEFECT:** Sum total of all defect pieces within the selected filter
